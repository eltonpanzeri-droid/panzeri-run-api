# Uso dos logos

- `symbol-primary.svg`: símbolo em Mineral Noturno para fundos claros.
- `symbol-reversed.svg`: símbolo em Calcário Quente para fundos escuros.
- `symbol-pulse.svg`: versão de alta presença; use em avatar, campanha e momentos de decisão.
- `logo-horizontal-dark.svg`: cabeçalhos e documentos claros.
- `logo-horizontal-light.svg`: fundos Mineral Noturno ou fotografia escura.
- `logo-stacked-dark.svg`: aplicações verticais e institucionais.

Os wordmarks permanecem como texto editável para facilitar a implementação. Antes de enviar a uma gráfica, o designer deve converter as fontes em contornos. No produto digital, prefira renderizar o símbolo como SVG e o nome com as fontes oficiais carregadas.
