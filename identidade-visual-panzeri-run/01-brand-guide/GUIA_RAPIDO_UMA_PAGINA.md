# PANZERI RUN / GUIA RÁPIDO

**Essência:** Direção que se adapta.

**Símbolo:** três marcas interrompidas — Planejado, Realizado e Próximo. Os vazios diagonais são o Intervalo Vivo: o lugar onde a realidade altera a próxima decisão.

**Cores:** Mineral `#071827` · Calcário `#F4F0E6` · Verde Pulso `#C7F36B` · Azul profundo `#246F91` · Névoa Azul `#B8E6EF`.

**Tipos:** Big Shoulders Display 800 para títulos; Public Sans para interface e leitura; JetBrains Mono para dados.

**Tom:** firme, direto, educativo, próximo. Nunca coach motivacional, infantil ou futurista.

**Composição:** estrutura forte + uma quebra controlada. Espaço amplo, cards claros, números expressivos, Verde Pulso apenas em decisões.

**Use:** a Tríade sozinha em avatar/ícone; assinatura horizontal em cabeçalhos; Intervalo Vivo em divisores, progresso, máscaras e transições.

**Não use:** corredor, tênis, pista, raio, chama, cérebro, chip, robô, ECG, escudo ou degradê de IA.

**Regra:** toda aplicação deve transmitir método, movimento e abertura à realidade.
