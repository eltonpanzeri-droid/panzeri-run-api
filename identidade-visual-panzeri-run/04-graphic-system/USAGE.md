# Sistema gráfico

## Intervalo Vivo

O corte diagonal pode aparecer como abertura em faixas, bordas, fotografias e indicadores. O ângulo deve permanecer em aproximadamente 24°; não variar aleatoriamente.

## Padrão

O padrão da Tríade deve ser usado em baixa opacidade, nunca atrás de textos longos. É indicado para finais de carrossel, fundos de Stories, embalagens digitais e seções institucionais.

## Progresso de três estados

O modelo `three-state-progress.svg` é conceitual. Na interface real, use os estados apenas quando houver de fato uma relação entre planejado, realizado e próximo. Não transforme toda barra de progresso em Tríade.
