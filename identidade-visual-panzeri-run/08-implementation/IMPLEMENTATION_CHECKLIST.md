# Checklist de implementação

## Preparação

- [ ] Criar branch exclusiva.
- [ ] Registrar screenshots atuais.
- [ ] Confirmar dependências de SVG e fontes.
- [ ] Importar tokens sem remover estilos antigos.

## Marca

- [ ] Ícone iOS exportado e validado.
- [ ] Adaptive icon Android testado em quatro máscaras.
- [ ] PWA 192 e 512 exportados.
- [ ] Splash claro validado.
- [ ] Onboarding sem ícone de pulso.
- [ ] Landing e app usam a mesma Tríade.

## Interface

- [ ] Tipografia carregada sem flash ou travamento.
- [ ] CTA Verde Pulso não conflita com erro/dor.
- [ ] Dados usam JetBrains Mono apenas onde ajuda.
- [ ] Cards migrados sem perda de densidade informacional.
- [ ] Foco e estados desabilitados visíveis.
- [ ] Texto a 200% não corta ações.

## Conteúdo

- [ ] “Orientação da semana” substitui linguagem de motor onde aprovado.
- [ ] Sem promessas de monitoramento humano em tempo real.
- [ ] Sem promessa absoluta de segurança.
- [ ] Tom firme, direto e não infantil.

## QA

- [ ] PWA Safari/Chrome.
- [ ] iOS físico.
- [ ] Android emulador e físico, se disponível.
- [ ] Fluxo completo: entrada → pagamento → entrevista → rotina → semana → feedback.
- [ ] Estados de dor e emergência preservados.
- [ ] Comparação visual aprovada por Elton.
